OS Control

Run python -m bridge and serve this page from http://localhost:8000. Push the RUN lever up: it links to the bridge by itself. Control starts paused; pull the RUN lever to arm. Point moves the real cursor; a quick pinch clicks where the cursor was 200 ms earlier; a pinch held over 450 ms drags; a peace sign moved up or down scrolls. Esc, a fist held 1 s, or losing the hand releases the mouse and pauses. An open palm held 2 s pauses or re-arms.

The bridge listens on localhost only, checks the page origin, rate-limits input and pauses itself after 1.5 s without a ping.
